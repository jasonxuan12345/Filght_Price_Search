使用说明

  • 打开页面后先输入 SerpApi Key，再点击查询；key 只保存在当前浏览器会话中
  • 选择航司后，系统自动遍历日期范围内的所有日期；目的地为 LON 时默认同时查 LHR 和 LGW
  • SerpApi 查询次数通常等于日期数 × 机场数；例如 6/1-6/30 查 LON 约需 60 次，单查 LHR 约需 30 次
  • “同时查询数”可以缩短等待时间，建议 3-8；太高可能触发限流或让单次请求更不稳定
  • 有 SERPAPI_KEY 时自动获取 Google Flights 实时价格并排序
  • 无 API Key 时显示参考航班组合 + 查价链接
  • 免费注册 SerpApi 账号即可自动获取实时价格：serpapi.com
